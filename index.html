Projects

Reduced Order Model for Urban Microclimate — Barcelona

Data-driven ML surrogate replacing CFD multiphysics simulations. Random Forest and Gradient Boosting regressors trained on ANSYS Fluent outputs predict air temperature, wind speed, and mean radiant temperature at sub-meter resolution from weather station inputs. Achieves ~200× speedup over full CFD.

Python scikit-learn Random Forest PCA ANSYS Fluent CFD K-Means
Report GitHub

Building Function Classification from Aerial Imagery — NYC

U-Net semantic segmentation model classifying 12 building use types from NAIP RGB aerial imagery across NYC. Trained on 19k image-mask pairs derived from PLUTO land use data. Achieves IoU of 0.71 on test data.

Python PyTorch U-Net NAIP GeoPandas GDAL
Report GitHub

VisTemp — Visual Air Temperature Prediction from Street View

CNN model combining semantic segmentation and temperature regression on street view imagery. Trained on the Cityscapes dataset; achieves mean IoU above 0.7 and RMSE of 5.6°C. With V Rinaldi.

Python PyTorch CNN Semantic Segmentation
Report GitHub

COVID-19 Impact on Building Energy Usage — NYC

Geospatial analysis of building energy consumption changes between 2019 and 2020 across NYC census tracts. ElasticNet regression and dominance analysis identify building volume, density, and daytime population as dominant predictors. Finds significant reduction in office and school energy use attributable to stay-at-home orders.

Python ElasticNet Dominance Analysis Google Earth Engine GeoPandas PLUTO
Report GitHub

ResNet for CIFAR-10 Classification — Under 5M Parameters

Custom ResNet architecture for image classification on CIFAR-10, built under a strict 5M trainable parameter budget. Systematic ablation across residual block configurations, data augmentation strategies, and training hyperparameters. Final model trained for 200 epochs and evaluated on a Kaggle competition test set.

Python PyTorch ResNet CIFAR-10 Deep Learning
GitHub

Mold Risk Prediction & Respiratory Health — NYC Building Stock

Random Forest classifier trained on 750k NYC residential properties to predict building-level mold risk from structural characteristics, flood zone data, and 311 complaints. Derives a neighborhood-level Mold Risk Index validated against asthma ER visit rates via ElasticNet regression — inclusion of the index improves R² from 0.59 to 0.68 for adult asthma rates.

Python scikit-learn Random Forest ElasticNet GeoPandas NYC Open Data PLUTO
Report GitHub

About

I am a geospatial data scientist and urban researcher with a background spanning land surveying, photogrammetry, remote sensing, and computational fluid dynamics. My PhD at NYU Tandon focused on microclimate modeling and GeoAI applications in dense urban environments.

My work sits at the intersection of physical simulation and machine learning — using CFD to generate ground-truth thermal fields, then training spatial models to predict and generalize at city scale. I have worked across Germany, Singapore, Abu Dhabi, and New York.

I am interested in roles combining geospatial engineering, climate risk analysis, and applied AI — especially where the output has direct operational or planning value.
